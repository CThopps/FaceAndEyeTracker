Simple Real-Time Face and Eye Tracker program using OpenCV
Program uses the Haar Cascades from the OpenCV repository (https://github.com/opencv/opencv/tree/master/data/haarcascades) to detect the user(s) face and eyes

This program is also build to function on the Rasberry Pi 4 using an external USB webcam (code is not tested with the Rasberry Pi Camera Module)

Note: the dependencies used for this program was downloaded through the pip package manager for Python and may cause errors if the package is installed using another method

To prevent any errors or to install the necessary dependencies, use the command :
`pip install opencv-python`
